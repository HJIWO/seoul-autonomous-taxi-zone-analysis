# 🚖 서울시 야간 택시 데이터 기반 자율주행 택시 도입 우선 구역 도출

> **2026 서울시 빅데이터 통합 경진대회 분석부문** 출품작  
> 팀명: **두산 라이온즈**

---

## 📌 프로젝트 개요

서울시 야간 택시 운행 데이터를 분석하여 **자율주행 택시 도입 우선 확대 구역 및 시간대**를 데이터 기반으로 도출한 프로젝트입니다.

현재 서울시는 강남구 7대 자율주행 택시 심야 시범운행(22:00~05:00)을 운영 중이나, 데이터에 근거한 확대 기준이 부재한 상황입니다. 본 분석은 서울 전체 **426개 행정동**을 대상으로 객관적 우선순위를 제시합니다.

---

## 🔍 분석 배경 및 필요성

### 공급 측 위기
- 개인택시 기사 평균 연령 **64.6세**, 전체의 **78%가 60세 이상**
- 법인택시 기사 평균 연령 **63.1세** → 심야 장시간 운행 안전 위험 증가

### 수요 측 위기
- 서울 426개 행정동 중 **177개(41.5%)** 가 올빼미버스 서비스 권역(500m) 밖에 위치
- 지하철 막차 이후(00~02시) 이용 수요 **96.5% 소멸** → 택시 의존도 급증

### 분석 타겟
**오피스 야근 귀가 수요**를 핵심 타겟으로 설정
- 목적지 명확 → 완전 자율주행에 최적화
- 평일 반복 패턴 → 수요 예측 가능
- 심야 대중교통 공백 시간대와 정확히 일치

## 🛠️ 분석 방법론

### 분석 파이프라인 (4단계)

```
[1단계] 오피스 밀집도 지수 산출
    └── J·K·L·M·N 5개 오피스형 업종 종사자 수 합산 → Min-Max 정규화

[2단계] 대중교통 공백 지수 산출
    └── 올빼미버스 500m 버퍼 생성 → 커버리지 비율 산정 → (1 - 커버리지)

[3단계] 야간수요 지수 산출
    └── KT 심야 유동인구 행정동별 합산 → Min-Max 정규화

[4단계] 복합지수 산출 및 우선순위 도출
    └── 복합지수 = 오피스 밀집도 × 0.35 + 대중교통 공백 × 0.35 + 야간수요 × 0.30
```

### 가중치 설계 근거
- **오피스 밀집도 (35%)**: 수요 존재 — 자율주행 도입의 필요조건
- **대중교통 공백 (35%)**: 공급 부재 — 자율주행 도입의 충분조건
- **야간수요 (30%)**: 실제 수요 보완 확인 지표

### 행정동 분류 기준

| 유형 | 조건 | 대상 수 | 확대 방향 |
|------|------|---------|----------|
| **오피스 밀집형** | 오피스 밀집도 지수 ≥ 0.2 | 23개 동 | 수익성 중심 1차 확대 |
| **복합형** | 오피스 밀집도 0.1~0.2 | 7개 동 | 별도 모니터링 |
| **교통공백형** | 오피스 밀집도 < 0.1 & 교통공백 ≥ 0.7 | 102개 동 | 이동권 형평성 확대 |

## 💡 기대효과

**① 안전 효과**  
심야 고위험 시간대 운행 일부를 자율주행으로 전환 → 고령 운전자 야간 운행 위험 구조적 감소

**② 이동권 형평성 효과**

**③ 경제적 효과**

**④ 정책 고도화 효과**  
최초의 데이터 기반 자율주행 택시 확대 기준 제시 → 향후 실시간 수요 예측 기반 동적 배차 시스템으로 발전 가능
